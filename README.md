# Voxel Hunt · Android-плейтест

Тут публікуються підписані Android-збірки Voxel Hunt і списки змін.

## Встановлення й оновлення

1. Відкрий [Releases](../../releases), завантаж `voxel-hunt-demo-v1-android.16.apk` і встанови його вручну.
2. Після цього гра сама перевірятиме наявність нових релізів при запуску. Перевірити оновлення вручну можна кнопкою **«Оновити»** справа внизу головного меню.
3. Встановлюй нові APK поверх попередньої збірки, щоб зберегти локальні сейви.

Хмарні сейви працюють через Firebase. Статистика кадрів і результати боїв надсилаються лише за згодою, яку можна змінити в налаштуваннях гри.
